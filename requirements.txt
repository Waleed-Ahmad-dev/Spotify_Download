# ── Windows only: capture the local Spotify app's "now playing" via GSMTC ─────
# Modern PyWinRT split packages — they ship per-Python wheels and pull in
# winrt-runtime automatically. No Spotify account or Web API is involved.
# (On older setups the legacy monolithic `winsdk` package also works; the code
#  imports whichever is present.)
winrt-Windows.Media.Control ; sys_platform == "win32"
winrt-Windows.Foundation ; sys_platform == "win32"
winrt-Windows.Foundation.Collections ; sys_platform == "win32"
